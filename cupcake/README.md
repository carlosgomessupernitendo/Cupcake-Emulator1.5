
# Android Cupcake Guest System

This directory contains the Android 1.5 guest system
integration.

## Target version

Android 1.5 Cupcake.

## API Level

3.

## Planned components

- Android framework
- Dalvik Virtual Machine
- Android Runtime libraries
- System applications
- Android Package Manager
- Original launcher
- System settings

## Source

The original AOSP Cupcake source will be investigated
and integrated here.

Third-party proprietary applications must not be
included without appropriate distribution rights.
