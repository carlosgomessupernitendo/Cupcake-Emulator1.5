
# Desktop Frontend

The desktop frontend will provide the emulator
for Windows, Linux and macOS.

## Goals

- Start and stop the virtual machine
- Display the original Android screen
- Support keyboard and mouse
- Support audio
- Import APK files
- Manage virtual storage
- Save emulator configuration

## Technology

- C++
- Qt 6
- CMake

## Platforms

- Windows
- Linux
- macOS
