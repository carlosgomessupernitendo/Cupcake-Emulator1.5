
# Installation Guide

## Android

The Android version will eventually be distributed
as a standalone APK.

Requirements:

- Android 12 or newer
- Sufficient free storage
- Compatible device architecture

## Windows

The desktop version will eventually be distributed
as a Windows installer.

## Linux

The desktop version will eventually be distributed
as a Linux package.

## macOS

The desktop version will eventually be distributed
as a macOS application.

## Android guest installation

The guest Android 1.5 system image will be installed
and configured separately from the host application.

## Current status

Installation packages are not available yet.
