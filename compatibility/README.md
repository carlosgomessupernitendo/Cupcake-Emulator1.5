
# Compatibility Testing

This directory contains APK compatibility tests.

## Test categories

1. APK parsing
2. APK installation
3. Application launch
4. Framework compatibility
5. Native library compatibility
6. Graphics
7. Audio
8. Network
9. Storage
10. Permissions

## Test results

Compatibility results must distinguish between:

- Not tested
- Installed successfully
- Started successfully
- Partially functional
- Fully tested
- Incompatible

A successful installation does not mean that
an application is fully compatible.
