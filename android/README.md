
# Android Frontend

The Android frontend is the mobile host application.

## Goals

- Run the Cupcake emulation engine
- Display the original guest screen
- Support touchscreen controls
- Support virtual keyboard
- Import APK files
- Manage virtual storage
- Save emulator configuration

## Technology

- Kotlin
- Android SDK
- CMake
- C++ native integration through JNI

## Target

Android 12 and newer for the initial release.

The guest operating system remains Android 1.5.
